# Cogno AI Ltd — Website

A modern, professional fintech company website for **Cogno AI Ltd**, built with Next.js, TailwindCSS, and Framer Motion.

## Tech Stack

- **Next.js 16** (App Router, static pages)
- **React 19** / **TypeScript**
- **TailwindCSS 4**
- **Framer Motion** (animations)
- **Lucide React** (icons)

## Project Structure

```
src/
├── app/
│   ├── page.tsx                  # Homepage
│   ├── layout.tsx                # Root layout (Header + Footer)
│   ├── globals.css               # Global styles & theme
│   ├── products/                 # DIY Tax Return product page
│   ├── technology/               # AI Technology page
│   ├── solutions/                # Solutions page
│   ├── about/                    # About Cogno AI
│   ├── contact/                  # Early Access / Contact form
│   ├── blog/                     # Blog listing + [slug] detail pages
│   ├── privacy/                  # Privacy Policy
│   └── terms/                    # Terms of Service
├── components/
│   ├── Header.tsx                # Navigation header (responsive)
│   ├── Footer.tsx                # Footer with company details
│   └── ui.tsx                    # Reusable UI components
```

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Build & Deploy

```bash
npm run build    # Production build
npm start        # Start production server
npx vercel       # Deploy to Vercel
```
